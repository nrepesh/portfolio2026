Assess Learners

Coursework / ML4T / Assess Learners

Problem

Build four supervised learners from scratch and characterize their behavior under controlled experiments.

Approach

  • Decision Tree, Random Tree, Bagging ensemble and Linear Regression, written in pure Python
  • Recursive split logic implemented directly, which exposes leaf size as the overfitting control
  • Three experiments: overfitting against leaf size, bagging's effect on it, and training time against accuracy
  • Consistent train-test split so the comparisons are like for like

Results

4 learners built
Experiment Finding
Overfitting vs leaf size At leaf_size=1, test RMSE was 0.0078 vs training RMSE of 0.0. Gap reduced to near-zero at leaf_size=6.
Bagging reduces overfitting? Yes, but not eliminated. DT bag ensemble test RMSE dropped to 0.0060 (from 0.0078). RT bag ensemble: 0.0064.
DT vs RT speed RT trained ~12x faster (0.025s vs 0.303s at leaf_size=1).
DT vs RT accuracy DT slightly higher R-squared (0.524 vs 0.488) due to correlated feature selection.

Bagging helps less on decision trees because they correlate, all selecting the same first feature; random trees decorrelate, which is exactly why weak learners ensemble well.
