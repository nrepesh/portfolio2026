// RAIT - Project 5

Policy Search

Coursework / RAIT / Policy Search

Problem

The same warehouse, but the robot's starting square is unknown, so the output has to be a policy giving an action for every square rather than a single route. The floor carries an uneven traversal cost, and in the second half motion is stochastic, so an intended move sometimes slips sideways.

Approach

  • Value iteration across the grid, run twice: one policy to reach the box, a second to deliver it
  • Carrying the box changes the state enough to warrant its own value function
  • Action cost combines the motion cost with the floor cost of the destination square
  • Under stochastic motion the update takes an expectation over every outcome of an intended move, not just the intended one
  • The deterministic half was restructured rather than patched once the state representation proved wrong

Stochastic motion changes the shape of the optimal policy, not merely its confidence: value iteration buys clearance from walls because a slip in a corridor costs more than the detour.
