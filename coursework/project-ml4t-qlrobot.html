Q-Learning Robot

Coursework / ML4T / Q-Learning Robot

What I Did

I implemented Q-Learning and Dyna-Q from scratch in Python to solve a discrete grid-world navigation problem. Q-Learning is model-free: the agent learns only from real experience with the environment. Dyna-Q augments this with a learned world model - after each real step, the agent performs additional "mental" updates by replaying experiences from a simulated model of the environment. The goal was to reach the target cell starting from a random position while avoiding walls, with reward shaping for both distance-to-goal and step count.

What I Learned

The biggest lesson from this project was the power of model-based planning. Model-free Q-Learning is simple and general, but it's wasteful. Every step teaches one state-action pair. Dyna-Q's insight is that you can learn a lot more from the same experience if you reuse it. After each real step, I updated the transition model T(s,a) -> s' and reward model R(s,a) -> r, then performed 50-100 simulated Q-updates using this learned model. This cut convergence steps by roughly 4-5x across all test worlds.

I also learned that exploration strategy matters far more than I expected. With pure greedy selection, the agent gets stuck in local optima - it finds one path to the goal and never explores alternatives. The epsilon-greedy approach (random action with probability epsilon) solves this, but tuning epsilon is non-trivial: too high and the agent never exploits what it learned, too low and it never discovers better paths. I ended up using a decaying epsilon schedule that starts at 0.9 and decays to 0.1 over 500 episodes.

Reward shaping was another critical insight. Without it, the agent wanders aimlessly because most states give zero reward. I added a distance-based reward that gives partial credit for moving closer to the goal, and penalties for hitting walls. This dramatically sped up learning because the agent gets feedback on every move, not just when it finally stumbles into the goal.

Architecturally, the Q-table is just a 2D array indexed by (state, action). But the real challenge was discretizing the continuous grid into discrete states while maintaining the Markov property. Too coarse, and the agent loses important spatial information. Too fine, and the state space explodes. I spent significant time tuning the state representation before finding a balance that worked robustly across different world layouts.
