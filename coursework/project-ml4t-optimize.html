Portfolio Optimization

Coursework / ML4T / Portfolio Optimization

What I Did

I implemented a full portfolio analysis toolkit and used SciPy's optimization routines to find the allocation mix that maximizes the Sharpe ratio for a given set of equities. The project covered four core metrics: cumulative return, average daily return, standard deviation (volatility), and Sharpe ratio. I then built an optimization solver that searches the simplex of valid allocations (summing to 1.0, all positive) to find the point of highest risk-adjusted return.

Key Results

Metric Optimized Portfolio Equal-Weighted
Cumulative return +32.6% +18.4%
Sharpe ratio (252-day) 2.06 1.28
Volatility (daily std) 0.0103 0.0137
Max allocation JPM (43%) 20% each

The optimized allocation shifted heavily into JPM (43%) and reduced exposure to AAPL and XOM, which had lower risk-adjusted returns individually. This was not obvious from looking at raw returns alone: JPM had moderate absolute returns but very low volatility, making it a Sharpe-ratio star.

What I Learned

The first thing that struck me was how differently the optimal portfolio looks when you optimize for Sharpe ratio versus raw return. A max-return optimization puts everything into the single best-performing stock, giving you maximum upside but also maximum volatility. Sharpe ratio forces a fundamentally different mindset: it rewards consistency and penalizes noise.

I also learned that the optimization surface is surprisingly sensitive to input assumptions. Small changes in expected return estimates can swing the optimal allocation by double digits. This taught me to be cautious about treating optimizer output as gospel. The optimal portfolio is a function of the data you fed it, and that data is backward-looking.

On the technical side, working with SciPy's minimize function for the first time gave me hands-on experience with constrained optimization. I had to set up linear constraints (sum of allocations = 1.0) and bounds (0 <= x <= 1) correctly, or the optimizer would produce portfolios that don't make financial sense. Getting the constraints right was as important as choosing the objective function.
