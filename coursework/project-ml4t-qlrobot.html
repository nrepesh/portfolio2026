Q-Learning Robot

Coursework / ML4T / Q-Learning Robot

Problem

Solve grid-world navigation with reinforcement learning, comparing model-free learning against model-based planning.

Approach

  • Q-Learning and Dyna-Q implemented from scratch over a Q-table indexed by state and action
  • Dyna-Q learns transition and reward models, then replays simulated updates after each real step
  • Epsilon-greedy exploration on a decaying schedule: exploration early, exploitation late
  • Reward shaped on distance to goal so feedback arrives every step, not only on arrival

Results

2 algorithms
World Q-Learn Steps Dyna-Q Steps Speedup
testworlds/world01.csv (10x10) ~350 ~80 4.4x
testworlds/world02.csv (10x10, more walls) ~500 ~110 4.5x
testworlds/testworld.csv (10x10, open) ~150 ~40 3.8x

Model-free learning extracts one state-action pair per step; reusing that same experience through a learned model cut convergence roughly four to five fold.
