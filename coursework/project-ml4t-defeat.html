Defeat Learners

Coursework / ML4T / Defeat Learners

Problem

Generate synthetic datasets that make one learner reliably beat another, in both directions.

Approach

  • A strictly linear relationship with light Gaussian noise, favoring the linear regressor
  • Piecewise-constant regions with axis-aligned boundaries, favoring the decision tree
  • Generation written as a pure function of the seed: same seed, same data; different seeds, different data

Results

2 datasets
Dataset Structure Winner
best_4_lin_reg Strictly linear y = mx + b with Gaussian noise Linear Regressor
best_4_dt Non-linear, piecewise-constant with axis-aligned boundaries Decision Tree

Matching a model's inductive bias to the structure of the data is the actual skill, which makes “try several models” principled rather than lazy.
