Solar System (Particle Filters)

Coursework / RAIT / Solar System (Particle Filters)

Problem

Localize a satellite released at an unknown point in a solar system. The first half provides a single noisy scalar per timestep, the summed gravitational pull of the planets. The second substitutes per-planet illumination readings and requires aiming a transmission at the home planet.

Approach

  • Particle filter over position and heading, chosen because the belief is genuinely multi-modal at the outset
  • Importance weights from a Gaussian measurement model, where sigma sets how sharply particles are discriminated
  • Resampling proportional to weight, with fuzzing to restore the diversity resampling destroys
  • Particles advanced on a bicycle motion model matching the satellite's own dynamics
  • The second half supplies a measurement vector rather than one scalar, constraining position far harder per timestep

A single scalar is consistent with many positions, so localization comes from accumulating weak evidence over time rather than from one clever inference.
