Portfolio Optimization

Coursework / ML4T / Portfolio Optimization

Problem

Find the asset allocation that maximizes risk-adjusted return for a basket of equities.

Approach

  • Portfolio metrics implemented from scratch: cumulative return, average daily return, volatility and Sharpe ratio
  • SciPy constrained minimization over the allocation simplex, with weights summing to one and no short positions
  • Objective set to negative Sharpe so the minimizer maximizes risk-adjusted return
  • Benchmarked against an equal-weighted allocation over the same period

Results

Metric Optimized Portfolio Equal-Weighted
Cumulative return +32.6% +18.4%
Sharpe ratio (252-day) 2.06 1.28
Volatility (daily std) 0.0103 0.0137
Max allocation JPM (43%) 20% each

Maximizing Sharpe rewards consistency where maximizing return concentrates everything in one name, and the optimizer is only ever as forward-looking as the data behind it.
