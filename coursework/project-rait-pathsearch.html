Path Search

Coursework / RAIT / Path Search

Problem

Route a warehouse robot to a box and deliver it to a dropzone, then convert the resulting grid path into a continuous path a real vehicle could actually drive.

Approach

  • A* over the warehouse grid, eight-connected, with distinct costs for straight moves, diagonals and box handling
  • The goal is the set of squares adjacent to the box, not the box square itself
  • Heuristic kept admissible; an overestimate silently forfeits optimality rather than failing loudly
  • Gradient-descent smoothing trading fidelity to the planned path against curvature
  • Worst turn angle located and repaired explicitly, then duplicate and corner points cleaned up

Smoothing pushed too far drifts into the obstacle the search routed around, so the two halves of the project optimize against each other.
